## Audience and job

Builders, developers, small teams and agencies that want a clear local workspace for project context, multiple working windows, session information and explicit connections to their tools or project memory.

## Positioning

A free, open-source, white-label dashboard base from ourark.io. Start locally, understand the actual data sources, and extend the workspace through documented adapter contracts. The long-term goal is one understandable interface for an orchestrated work environment; the current release must state exactly which capabilities are implemented, demo-backed or planned.

## Message pillars

1. See the task and its context together.
2. Adapt supported branding settings to your project.
3. Understand what is connected, how, and with what evidence.
4. Connect the documented local JSON memory source, then build further adapters deliberately.
5. Inspect, contribute and improve the open codebase.

Benefits are qualitative unless measured. Never invent time savings, benchmarks, adoption, customer quotes or platform results. Do not claim every service is already connected. Local JSON memory is read-only with text search, provenance/hashes and context JSON export; it does not automatically inject content into a model and is not vector search. Binding is through the documented `--connections-config` path and scope. A runtime name is not proof of the model used. Demo usage is not a real API bill.

Brand configuration covers the supported name, monogram, tagline, website, accent and light/dark settings; do not promise arbitrary logo upload. The current spatial presentation is CSS 2.5D, not Three.js. Automation examples are local one-step drafts, not a verified cloud workflow engine. Six code/session panes may use demo content. The metadata/event bridge does not prove an actual model request ran.

## Tone and channels

Clear, practical, specific and friendly. Main campaign captions and scripts are English; planning is German. TikTok, Instagram Reels, X and YouTube Shorts use the same verified product truth with platform-specific text. One useful point and one concrete CTA per post. Avoid hype, guaranteed growth and manufactured urgency.

# Produktionscheck je Tagesmotiv

## Paket, das Claude Code erzeugt

Arbeitsausgabe unter `marketing-output/day-NN/` in einem privaten oder ausdrücklich vorgesehenen Medien-Arbeitsverzeichnis. Große Medien nicht ungefragt in den Quellcodeverlauf aufnehmen. Die öffentliche Dokumentation bleibt unter `docs/marketing/`.

| Datei | Inhalt |
|---|---|
| `brief.md` | Ziel, Zielgruppe, Hook, Claim-IDs, gewünschte Aktion |
| `script.md` | finales gesprochenes Skript und Shotlist |
| `master.mp4` | tatsächlich gerenderter, geprüfter Masterclip |
| `captions.srt` | zum Ton passende Untertitel mit echten Zeitcodes |
| `cover.png` | eigene Covergestaltung mit lesbarem Titel |
| `platform-copy.json` | vier angepasste Veröffentlichungstexte und jeweilige Assets |
| `evidence.md` | Commit, UI-Nachweise, Quellen, Demo-Kennzeichnung, Claim-Prüfung |
| `qa.md` | tatsächliche Medien-/Text-/Linkprüfung und offene Punkte |

## Vor Aufnahme

- Aktuellen Commit und veröffentlichte README prüfen; unterstützte Funktion demonstrieren.
- Synthetische Projekte, Sessions und Memory verwenden; Secrets, private Namen, Pfade, E-Mails und Browser-Tabs aus der Aufnahme halten.
- Demo-Daten deutlich kennzeichnen. Live-/Verbindungsstatus nicht für ein schönes Bild manipulieren.
- Originalprodukt, White-Label-Beispiel und Roadmap visuell auseinanderhalten.
- Nur freigegebene Logos und passend lizenzierte Medien verwenden. Fiktive Marken sind keine Referenzkunden.

## Schnitt und Texte

- 9:16 als Masterformat, 20–45 Sekunden als eigenes Produktionsziel. Beschriftungen am Smartphone prüfen.
- Hook direkt mit dem tatsächlichen Bild belegen. Ein Clip erklärt einen Ablauf.
- Untertitel korrekt, kontrastreich und nicht über wichtigen UI-Informationen platzieren; Interface-Bedienelemente der Plattform beim finalen Upload berücksichtigen.
- Keine hektischen Daueranimationen oder blinkenden Alarmanzeigen zur künstlichen Dramatisierung.
- Ein klarer CTA. Kurze URLs/Profilhinweise nur nutzen, wenn ihr tatsächliches Ziel geprüft ist.
- Titel, Caption, Cover und gezeigter Release erzählen dieselbe überprüfbare Aussage.

## Abschluss

- Video vollständig abspielen; Audio, Bild, Untertitel und sichtbare Daten prüfen.
- Vier Kanaltexte aus demselben geprüften Inhalt ableiten. Keine fremden Plattform-Wasserzeichen.
- Verwendete Dateien, Lizenzherkunft und reale Ergebnisse im Tagespaket notieren.
- Veröffentlichung nur auf den tatsächlich vorhandenen, beauftragten Konten mit passendem Zugang. Vorliegende ausdrückliche Mandate weiterverwenden; bei fehlenden Zugängen nur den betroffenen Schritt offen lassen.
- Nach erfolgter Veröffentlichung die echte URL und Zeit in `publishing-log.csv` erfassen. Eine exportierte Datei ist keine veröffentlichte Datei.
- Plattformwerte aus ihrer Originaldefinition übernehmen; fehlende Daten leer lassen. Nach 24h, 72h und 7d prüfen, soweit der Account die Daten anbietet.
